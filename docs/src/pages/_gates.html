06The four gates

Four gates. In order. No skipping.

The first three run on every step. The last one is you, at the end. Work with nothing to look at, like an API change or a refactor, skips gate 2.

Gate 1Waiting

Tests

Has to be true
Tests are written before the code. At least one fails on an assertion. Then all of them pass.
How it's enforced
Ratchet runs the tests itself and reads each planned test's own result. A test that crashed, was skipped or never ran doesn't count. None may be deleted.
  • Planned tests are frozen after their first failing run. Changing one needs your OK.
  • A test that already passes before the code exists isn't testing anything.
Gate 2Waiting

Looks right

Has to be true
The screen matches the design, or the old screen if you're rebuilding one, in the same state.
How it's enforced
Both are opened in a browser, put in the same state, clicked through the same actions and screenshotted. Two reviewers list every difference. Any difference that can be fixed in code blocks the step.
  • One reviewer checks how it looks. The other checks how it behaves: clicks, typing, errors.
  • They only see screenshots and the design file, never the code or the chat.
  • If the two screenshots aren't showing the same thing, the comparison is thrown out and redone.
Gate 3Waiting

Review

Has to be true
Reviewers try to break the code and find nothing serious.
How it's enforced
Rounds keep going until no reviewer has a blocking finding on the current code. A review only counts if it was signed for that exact round, or written by the agent's own reviewer.
  • Every finding must say who is harmed and how, judged against the plan's objective.
  • Small nitpicks stop blocking after two rounds and are listed for you at the end.
Gate 4Waiting

You

Has to be true
You try it and say yes.
How it's enforced
Only a real message from you counts. Messages your CLI sends on its own, like a background task finishing, are never taken as your reply.
  • A thumbs-up, an "ok" or a yes with a "but" on the end doesn't count. Try it yourself.
