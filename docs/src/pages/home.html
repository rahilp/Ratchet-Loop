The problem

The agent checks its own work.

When a coding agent builds a feature, the same agent writes the tests, runs them and decides when it's done. Nothing stops it from writing tests that already pass, skipping a check, or calling a screen finished without looking at it.

On a small change, you catch this in review. On a feature with eight steps, the mistakes pile up, and you find them at the end, all at once.

So you end up watching the agent and testing everything yourself.

The fix

Ratchet Loop checks every step for you.

Ratchet Loop splits a feature into small steps. Each step has to pass four gates before the next one starts: its tests, a check against the design, a review by a different AI, and finally your OK.

The agent can't skip a gate. Hooks in your CLI block it.

With Ratchet Loop, you can:

Leave the agent to work

You approve the plan and try the result. In between, it works on its own and posts a one-line update after each step.

Trust it when it says done

A step only counts as done after its tests pass, its screens match the design and a second AI has reviewed the code.

Catch bugs where they start

Each step is checked and committed before the next one starts, so a bug can't hide under later work. Any step can be undone on its own.

Keep the cost in check

Review rounds are capped per step and per run. Paid tools are never used without your OK. When the agent gets stuck, it stops and asks you.

Compared with TDD

Isn't this just TDD?

TDD is one of the four gates. Asking an agent to use TDD helps, but the agent still runs its own tests, reports its own results and decides when it's done. Ratchet takes those jobs away from it.
