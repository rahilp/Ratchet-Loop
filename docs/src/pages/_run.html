03A whole run

From one sentence to a finished feature.

Here is everything that happens, in order. You're needed twice: once to OK the plan, and once at the end. Step through it, or let it play.

YouUse Ratchet to build this feature: managers can approve or reject their team's leave requests, with a reason.

AgentGot it. A couple of quick checks first, then I'll show you the plan.

You ask, in your own words

That's all you type. Keep it to one feature. Something you can explain in a few sentences usually becomes three to eight steps. If it's bigger, split it.

The agent may ask a few quick questions first, instead of guessing.

  • Ratchet's hooks are working in this CLI
  • Another AI can review: Codex, signed in
  • No spec written yet, so the plan will be the spec
  • The app starts and the tests run
  • You're on your main branch. Start a new one?

It checks a few things on its own

Are the hooks working? Which other AI tools are installed that could review? Has your team already written a spec for this? If something would get in the way, like the app not starting, no way to run tests, or unsaved changes, it tells you in one message and offers to fix each one.

You read the plan and say yes

It opens with the objective: who it's for, what they want, what done means, and what's out of scope. Every step, reviewer and finding points back to it. Each step says what "done" means, whether its look is checked, how risky it is and who reviews it.

New screens come with a clickable prototype, so you see the result before anything is built. Once you say yes, the plan, the design file and the prototype are locked.

Now you can walk away

For each step, the agent writes the tests first and makes sure they fail. Then it writes the code until they pass. Then reviewers go looking for problems, and anything they find gets fixed and checked again.

Every finished step becomes its own git commit, and you get a one-line update as each one lands.

If a step gets stuck, it asks you

Each gate gets a limited number of tries. When they run out, the run stops. The agent quotes the problem and gives you two or three options, labelled A, B and C, with the one it recommends. Just reply with the letter.

Nothing gets lowered or skipped unless you pick it.

You try it and sign off

When everything is built, the agent tells you what to try. It also lists any small issues the reviewers noted but didn't hold things up for, and asks if you want any fixed.

Say "approved" if you're happy. If not, say what's wrong in your own words. Your changes become new steps, through the same gates.

Prefer to check every step yourself, or not be asked at all?

Just say so. By default you're asked twice: the plan and the end. You can ask to approve every step, or to only check in at the end after the plan. You can also say "pause" at any time and "carry on" later, even from a new chat.
