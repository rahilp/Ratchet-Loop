Ratchet Loop: step‑by‑step building for AI coding agents

Let the agent build. Then make it prove each step.

Ratchet Loop is a plug-in for Claude Code, Codex, Gemini CLI and Copilot CLI. It splits a feature into small steps. Each step has to pass its tests, match the design and get through a review by a different AI before the next step starts.
