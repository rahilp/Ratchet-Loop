The three steps

You install Ratchet once per computer, not once per project. After that it's there in every project you open, and it stays out of the way in projects where you don't use it.

  1. 01Ask your agent to install it

    {{INSTALL_PROMPT}}

    Open your agent in any folder and paste this. It asks before changing anything. Setup adds hooks to your CLI. Hooks are what stop the agent from skipping a gate.

  2. 02Restart your CLI, then say

    Set up Ratchet and continue

    Hooks load when the CLI starts. The agent checks they work, then asks what you want to build.

  3. 03Build something

    Use Ratchet to build this feature: describe it in a sentence or two.

    Run it in your project folder. Then describe the feature in a sentence or two.

What you need

A git repository and Python 3.8 or newer. For screens, Ratchet also uses Node 18+ and Playwright. It offers to install them.

Only for one project?

Ask your agent to "install Ratchet Loop for this project only". If you use more than one CLI, install it in each one.

Codex, Gemini or Copilot

Claude Code finds Ratchet on its own. For the others, the agent links Ratchet into your CLI's skills folder for you.
