15Install

Install once. Then just ask.

You install Ratchet once per computer, not once per project. After that it's there in every project you open. The hooks do nothing in projects where you're not using Ratchet.

  1. 01Ask your agent to install it

    {{INSTALL_PROMPT}}

    Open your agent in any folder and paste this. It asks before it changes anything. Part of setup is adding hooks to your CLI, which is what stops the agent skipping a gate.

  2. 02Restart your CLI, then say

    Set up Ratchet and continue

    Hooks only load when the CLI starts. The agent checks they work, tells you Ratchet is ready, and asks what you'd like to build.

  3. 03Build something

    Use Ratchet to build this feature: describe it in a sentence or two.

    Open your agent in your project folder. A real one: "managers can approve or reject their team's leave requests, with a reason."

What you need

Your project in a git repository, and Python 3.8 or newer. If you're building screens, Ratchet also uses Node 18+ and Playwright for screenshots, and offers to set them up.

Only for one project?

Ask your agent to "install Ratchet Loop for this project only". If you use more than one CLI, ask each one to install Ratchet for itself.

Codex, Gemini or Copilot

Claude Code finds Ratchet's skills on its own. For the others, the installer keeps one shared copy, and the agent can link it into your CLI's skills folder for you.
