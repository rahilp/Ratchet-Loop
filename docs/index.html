AI coding agents will tell you it works. Ratchet Loop makes them prove it.

Ratchet Loop works inside Claude Code, Codex, Gemini CLI and GitHub Copilot CLI. You describe a feature, and your agent builds it in small steps, checking each one before it moves on. You don't type any commands. You talk to your agent like normal.

Stop checking your agent's work by hand

Coding agents are fast, but they'll tell you something works when it doesn't. The same agent writes the tests, runs them and decides it's finished. So the gaps show up later, when you try the feature yourself.

With Ratchet, your agent splits the feature into small steps and builds them one at a time. A step can't start until the last one has passed its checks. If a check fails, the agent fixes the problem and tries again. It can't argue its way past.

Walk away while it builds

You OK the plan and try the result at the end. In between, you get a one-line update as each step lands.

“Done” means checked

A step only counts once its tests pass, the screen matches the design and a second AI has reviewed it.

Find a bug in the step that made it

Every step is its own git commit. If something breaks, you know where, and you can undo just that step.

Keep review costs in check

Review rounds have limits per step and per run. Paid tools are never used unless you say so. If the agent gets stuck, it stops and asks you.

What happens on every step

The agent writes the tests first and makes sure they fail. Then it writes the code until they pass. The screen is compared with the design, and a reviewer from another AI goes looking for problems. Anything it finds gets fixed and checked again. Once nothing serious is left, the step becomes a commit and the next one starts.

Press play to watch a run, or click a stage to see who does it.

What happens when the agent misses something?

Say you ask for this: managers can reject a leave request, with a reason. The agent adds the button and writes some tests. They pass, because it wrote them after the code. It never checked that the reason is required.

Bug caught before the commit. Step 4 starts on working code.

On its own, the agent finishes first and the bug ships. With Ratchet, the reviewer catches it, the fix comes with its own test, and the step is committed before the next one starts.

Isn't this just TDD?

Tests first is part of it. It's gate 1. But when you ask an agent to do TDD, it still runs its own tests and decides when it's done. Ratchet runs the tests itself, won't let them be edited to pass, and adds three more checks after them.

Install guide

Questions people ask

Which coding agents does it work with?

Claude Code, Codex, Gemini CLI and GitHub Copilot CLI. Install it once on your computer for each CLI you use. Claude Code has the strongest safeguards, because its hooks can tell which agent is acting. The Gates page shows what each CLI checks.

How long does it take?

A small feature usually takes 20 to 60 minutes. Bigger ones take longer. The agent works on its own, so you don't have to watch.

Is it expensive?

It uses more AI time than letting the agent write code unchecked. To keep that down, Ratchet limits review rounds per step and per run. It uses one reviewer for low-risk steps and cheaper models for simple jobs. It never uses a pay-per-use tool without your OK.

Do I need other AI tools installed?

No. Without them, Ratchet uses a different model from the same company. If you have another tool set up, like Codex, Gemini, Copilot, Cursor or OpenCode, that tool reviews first. A model from another company spots different mistakes.

Where does my code go?

Into your project, with one git commit per finished step. If you're on your main branch or have unsaved changes, the agent offers to make a new branch first. Ratchet keeps its notes in a .ratchet/ folder.

Can I stop halfway?

Yes. Say pause. When you're ready, say carry on. You can pick it up in a new chat too. Nothing is lost.

What if I don't like the result?

Say so at the end, like you would to a colleague. Your feedback becomes new steps, and the agent saves the lesson for next time.

What if the reviewers keep finding the same mistake?

The agent offers to add an automatic check, like a lint rule. After that the mistake is caught in seconds. You decide.

The agent says the hooks aren't working.

Close the CLI, open it again in the same folder, and say: Set up Ratchet and continue. If that doesn't work, ask it to check that Ratchet's hooks are installed for this CLI.
