Specs and CI

Works with what you already use.

If your team writes specs

OpenSpec, GitHub Spec Kit and BMAD are supported.

Ratchet builds from your spec instead of writing its own plan. Each scenario gets a test that must pass. Each task goes into a step. If something is left out, the plan says why. As steps pass, Ratchet ticks off the tasks in your spec files.

Use Ratchet to build the add-dark-mode change. Use Ratchet to build story 1.3.

No spec tool? The plan you approve works as the spec.

Keep the checks running in CI

Say "Ask your agent to set up CI."

Ratchet writes a GitHub Actions workflow. It runs your tests and the checks saved during your runs on every push and pull request.

The AI reviews don't run in CI, because CI machines don't have your AI tools signed in. Ratchet never replaces a workflow you wrote yourself.
